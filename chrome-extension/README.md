# HEM SmartTrack → idMe (Chrome/Edge)

Extension ini membantu guru memindahkan rekod kehadiran yang **sudah hijau dan disahkan pelayan** daripada E-JKM ke borang idMe. Extension tidak menyimpan kata laluan dan tidak menekan butang hantar.

## Cara pasang untuk ujian

1. Ekstrak fail ZIP extension.
2. Buka `chrome://extensions` (Chrome) atau `edge://extensions` (Edge).
3. Hidupkan **Developer mode / Mod pembangun**.
4. Tekan **Load unpacked / Muat tanpa pembungkusan**.
5. Pilih folder `hem-smarttrack-idme-extension` yang telah diekstrak.
6. Pin ikon **HEM → idMe** pada bar alat pelayar.

## Cara guna

1. Buka E-JKM HEM SmartTrack dan pilih **Nama pengisi**.
2. Tekan ikon extension → **Ambil data kelas saya**.
3. Tekan **Buka idMe** dan log masuk menggunakan akaun guru sendiri.
4. Buka **Pengurusan Murid → Pengurusan Sahsiah → Pengurusan Kehadiran**.
5. Pastikan kelas dan tarikh betul, kemudian tekan ikon extension → **Isi kehadiran sekarang**.
6. Semak semua murid sebelum cikgu sendiri menekan butang **Kemaskini**.

Jika nama pengisi tidak sama dengan nama guru kelas, extension hanya akan meminta cikgu memilih kelas daripada satu senarai ringkas.

## Had dan keselamatan

- Versi ini untuk Chrome/Edge komputer.
- Rekod disimpan secara setempat dalam extension dan luput selepas 24 jam.
- Extension tidak membaca atau menyimpan kata laluan.
- Extension tidak menghantar borang secara automatik.
- Nama murid tidak hadir boleh ditaip secara ringkas, contohnya `Hana Afina` atau `TrizuanShah`. Padanan mesti unik; jika dua murid mempunyai nama hampir sama, tambah sedikit lagi rujukan nama.
- Beberapa nama boleh dipisahkan menggunakan koma, perkataan `dan`, tanda `&`, `/`, `+`, titik koma atau baris baharu.
- Bagi murid tidak hadir, extension menetapkan `Masalah Kesihatan → Demam` hanya apabila ruangan sebab masih kosong. Guru boleh mengubahnya sebelum menekan `Kemaskini`; pilihan guru yang sedia ada tidak akan ditimpa.
- Extension menyemak kelas, tarikh dan bilangan murid sebelum menyediakan tanda kehadiran.
- Jika nama murid tidak hadir tidak dapat dipadankan dengan tepat, extension berhenti tanpa mengubah senarai.
- Jika susun atur idMe berubah, padanan medan mungkin perlu dikemas kini.
- Jangan hantar borang jika medan yang ditandakan hijau tidak sepadan dengan label sebenar.
